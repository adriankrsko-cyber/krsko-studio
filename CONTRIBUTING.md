# Contributing to Krsko Studio

Start with a bug report describing the expected result, what happened and your browser. Use fictional client records. Do not attach real invoices, tax identifiers, bank details, API keys or backup files containing private data.

For a change:

1. Fork the repository and create a focused branch.
2. Run the static app locally using the README instructions.
3. Keep dependencies minimal and preserve existing browser data.
4. Check the job, invoice and reporting flows relevant to your change. For financial calculations, include boundary cases and explain the result.
5. Open a pull request explaining the user problem, implementation and validation.

Do not present country-specific tax behavior as universal. New integrations need explicit consent, least-privilege access and a clear distinction between reading, drafting and sending.

This is a new solo-maintained project. Contributions are reviewed as time permits.
