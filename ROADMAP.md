# Roadmap

This is a plan, not a list of working integrations.

## Next

- Improve invoice correction and credit-note workflows.
- Add validation for date consistency and stronger backup recovery.
- Add a month calendar, editable reminders and translations.
- Add accessibility and real workflow checks with other freelancers.

## Connected workflow

- Authenticated multi-device storage with ownership checks, backups and export.
- Gmail connection with explicit consent, limited access and revocation. Suggest jobs from selected conversations; show the source and require review before saving important billing details. Never automatically send messages or invoices.
- Google Calendar sync with user-selected calendars, stable IDs, duplicate prevention and explicit review of changes.
- Optional Claude assistance for structuring briefs and drafting summaries. Explain which data is sent and keep API keys server-side.

## Accounting support

- Configurable country, tax registration and reporting frequency.
- User/accountant-confirmed deadlines and reminders, with dated official sources. Distinguish invoice deadlines from VAT return/payment deadlines.
- Reviewed exports for accounting tools. No automatic tax submission in the initial scope.

No delivery dates or eligibility promises are made. Priorities should follow real feedback.
